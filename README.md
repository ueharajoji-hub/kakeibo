# 週予算の家計簿

一週間ごとに予算を決めて、週末に振り返る家計簿。iPhone のホーム画面に置いて使う PWA。
人に見せられる画面と、自分だけが見る画面を切り替えられる。

## 動かす

```
node serve.js          # http://localhost:8080
node test/logic.test.js   # 集計とプライバシー除外のテスト
```

`index.html` をダブルクリックしても中身は見られるが、`file://` では Service Worker と
通知が動かないので、確認は `serve.js` 経由がよい。

iPhone のホーム画面に置くには https が必要。GitHub Pages にこのフォルダをそのまま上げれば動く。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み。4つのタブ（入力 / 今週 / 振り返り / 設定） |
| `style.css` | 見た目。ダークモードと iPhone のセーフエリア対応 |
| `db.js` | SQLite(sql.js) を IndexedDB に保存する層。スキーマとシードもここ |
| `repo.js` | SQL は全部ここ。**画面側は絶対に SQL を書かない** |
| `app.js` | 画面の描画とイベント。円グラフもここ（依存ライブラリなしのインラインSVG） |
| `sw.js` | オフライン用キャッシュ |
| `serve.js` | 動作確認用の静的サーバ（依存なし） |
| `test/logic.test.js` | sql.js と IndexedDB を差し替えて `db.js` / `repo.js` を Node で走らせるテスト |

## 決めた仕様

- **金額は円の整数**。`amount_yen INTEGER` で持ち、小数は一切使わない
- **日付はローカル日付の文字列**（`'YYYY-MM-DD'`）。タイムスタンプで持つと、
  タイムゾーンや夏時間で週の境界がずれる
- **カテゴリは削除しない**。`is_hidden` を立てるだけ。過去の明細が壊れないように
- **予算は週ごとのスナップショット**。`week_budgets` にその週の額を固定して保存する。
  あとで既定額を変えても、過去の週の達成判定は動かない
- **繰り越しなし**。毎週リセット
- **円グラフの色は6枠まで**。上位5カテゴリ＋「ほか」にまとめてから描く。
  7色を超えると隣どうしの区別がつかなくなるため。色の順番は決め打ちで、
  増やしたり回して使い回したりしない。色覚の型が違っても隣と区別できることを
  検証済みなので、[style.css](style.css) の `--s1`〜`--s5` は差し替えないこと。
  明るい側は白地に対して 3:1 を切る色があるので、**凡例に必ず名前・割合・金額を出す**
  （色だけで読ませない）
- **収入は支出と同じ `entries` に入れる**。区別はカテゴリの `kind`（`'expense'` / `'income'`）。
  収入は予算・支出合計・「無駄だった」集計には混ざらず、今週タブに合計だけ別に出す。
  満足度は付けない（`repo.addEntry` がカテゴリを見て `NULL` にする）

## 個人モードと共有モード

右上のボタンで切り替える。ヘッダの色が変わるので、どちらにいるかは一目で分かる。

| | 個人モード | 共有モード |
| --- | --- | --- |
| プライベート印の明細 | 見える | **完全に消える**（合計からも抜ける） |
| 既定プライベートなカテゴリ | 見える | 行そのものが出ない |
| 切り替え | PIN が必要 | ワンタップで即座に |

隠す方向は確認なしで一瞬で入れる。戻るときだけ PIN を求める。急に画面を見せることに
なったときに手間取らないようにするため。

**漏れを防ぐ作り**：プライベート除外は [repo.js](repo.js) の `privateClause()` と
`weekBudgetRows()` の2箇所にしか書かれていない。合計・グラフ・明細・振り返りは
すべてそこを通る。新しい画面を足すときも、`repo.js` に関数を足して
`includePrivate` を受け取る形にすること。画面から直接 SQL を書くと、そこだけ
フィルタが漏れる。

### プライベートの付け方

- カテゴリに「既定でプライベート」を立てると、そのカテゴリを選んだ時点で
  自動でチェックが入る（毎回思い出さなくていい）
- 個別の明細だけプライベートにしたいときは、入力画面のチェックボックス

## 通知について

iPhone の Web アプリは、**ホーム画面に追加したときだけ**通知が使える（iOS 16.4 以降）。
さらに、アプリを閉じている間に自分から通知を出すことはできない。Web Push を使うには
サーバが必要になる。

なので今の実装は「アプリを開いたときに、先週の振り返りが未記入なら知らせる」まで。
週末のリマインドは iOS のリマインダーアプリで繰り返し通知を作るのが確実。

## データの置き場所とバックアップ

データはこの端末の IndexedDB の中だけにあり、どこにも送られない。
ただし Safari は、しばらく使わないサイトのデータを消すことがある。
設定画面から書き出せるファイルはそのままの SQLite なので、PC でも開ける。

```sql
-- 書き出したファイルはこう読める
SELECT c.name, SUM(e.amount_yen)
FROM entries e JOIN categories c ON c.id = e.category_id
WHERE e.date BETWEEN '2026-09-28' AND '2026-10-04'
GROUP BY c.id;
```

## まだ入っていないもの

- 固定費・サブスクの管理
- 月次の集計（給料は月1回なので、週だけだと収支が見えない）
- レシート写真
- CSV 取り込み
- 共有用レポートの画像書き出し（画面を渡さずに見せるため）
